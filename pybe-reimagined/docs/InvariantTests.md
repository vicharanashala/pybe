## How to add a new invariant

1. Add the entry to `tests/invariants/_map.ts`.
2. Write the test in the matching `tests/invariants/<category>.test.ts(x)` file.
3. Re-run `npm run generate-invariant-docs` to refresh this file.
4. The `tests/invariants/data.test.ts` meta-tests assert the registry stays in sync.

## How to fail CI

- **Remove any invariant test** → meta-test "every test name literally appears" fails.
- **Remove the registry entry** → meta-test "every invariant has at least one test" fails.
- **Introduce a score cap** (e.g. `Math.min(score, 9999)`) in `ScoringEngine.ts` → `INV-PB-3` test fails.
- **Add a hardcoded metaphor ID list** → `INV-A2` test fails.
