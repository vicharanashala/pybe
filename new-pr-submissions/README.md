# Chai Ki Dukaan
A story-driven browser game that teaches **Python variables** through running a chai stall.

## How the Game Teaches
You play as a chai wala. You store chai price, cups, and total money in variables like `chai_price = 10`. You change them, and see the result in the game.

## Entry Point
`python-variables-chai-ki-dukaan/index.html`

## Dependencies
- A modern web browser.

## How to Run
Just double-click `index.html` to open in browser. No server needed.
