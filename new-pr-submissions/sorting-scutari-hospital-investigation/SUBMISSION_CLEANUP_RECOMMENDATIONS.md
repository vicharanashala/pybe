## 5. Standalone HTML decision

The current project contains `index.html` only. `Sorting_Investigation.html` is **not present** in the live project. A generated candidate exists outside the project in temp storage, but it is not part of the submission and should not be copied in without an explicit decision.

PyBe examples include both direct-open and server-backed applications. This project is server-backed: the Exercises and Final Mission call `/api/execute`, and the comparison lab calls `/api/benchmark`. A flattened single-file HTML copy would duplicate source and could imply real Python execution where only a compatibility subset exists.

Recommendation: submit `index.html` as the declared entry point and document `python server.py`. Do not add a second standalone HTML file unless the author explicitly wants a browser-subset demo and labels its limits clearly.
