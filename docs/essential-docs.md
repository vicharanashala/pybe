# Essential Docs — Story-Based Discovery Learning Framework

**Author:** Ravada Lakshitha
**Email:** ravadalakshitha6@gmail.com
**GitHub:** https://github.com/RAVADA-LAKSHITHA

## Summary

This contribution introduces a reusable story-based discovery learning
framework for PyBe, designed around the philosophy "Think First. Discover
Next. Code Last." Instead of introducing Python syntax first, each lesson
begins with a relatable story that encourages learners to observe,
reason, and discover the underlying programming concept before seeing its
Python implementation. Python is presented as a way to express an idea
the learner has already understood, rather than the starting point of the
lesson.

## Scope

The current implementation demonstrates the framework through three
representative Python concepts. These three lessons are a partial
demonstration of the framework, not its ceiling:

| Concept | Lesson |
|---|---|
| Loops | Thirsty Crow |
| Conditional statements | Crane and Fish |
| Functions | Adder |

The underlying architecture is designed to extend to further concepts —
recursion, lists, dictionaries, classes, and others — as future
contributions build on it.
