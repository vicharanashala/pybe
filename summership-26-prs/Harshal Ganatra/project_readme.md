# PyBe: The Thieves at the Well

An interactive, narrative-driven web application designed to teach Python programming fundamentals through historical folklore. By leveraging the classic tale of Tenali Rama, PyBe separates logical intuition from programming syntax to reduce cognitive load for beginners.

## Features
* **Cinematic Storybook UI:** High-resolution, photorealistic imagery presented in a vertical "Hero Layout" for an immersive reading experience.
* **Progressive Learning:** Concepts are introduced intuitively through storytelling before transitioning to technical syntax.
* **Interactive Knowledge Checks:** Narrative-based MCQs with balanced distractor options that must be answered correctly to unlock subsequent acts.
* **The Royal Coding Trials:** A dedicated coding section where users translate the story's logic into actual Python syntax using fill-in-the-blank challenges.

## Tech Stack
* **Frontend:** React (Vite)
* **Styling:** Custom CSS (Cinematic Flexbox Layout)
* **Data Management:** Local JSON (`db.json`) for seamless state and content management.

## Installation & Setup
1. Clone the repository.
2. Navigate to the client directory: `cd client`
3. Install dependencies: `npm install`
4. Ensure the 5 story images (`act1.jpg` to `act5.jpg`) are placed in the `/public` directory.
5. Start the development server: `npm run dev`
