# दशावतार — The Many Forms

A scenario-first PyBe learning experience for **Python Polymorphism**.

## Goal
The learner first discovers the pattern **one purpose → many forms → different responses**, then maps it to Python.

## Teaching flow
1. One Purpose
2. The Great Flood — Matsya
3. The Impossible Constraint — Narasimha
4. Strategy over Force — Vamana
5. Story → Python Mapping
6. Polymorphic Dispatch Lab
7. Polymorphism Reveal
8. Inheritance vs Polymorphism
9. Duck Typing
10. Real-Software Transfer Challenge
11. Reflection / Concept Mastery

## Why the animations matter
Animations are instructional:
- the Dharma Chakra represents the common request;
- one method pulse branches to different objects;
- each receiver highlights when the same method is dispatched;
- story elements map directly to Python abstractions;
- inheritance and polymorphism are shown with different visual structures.
