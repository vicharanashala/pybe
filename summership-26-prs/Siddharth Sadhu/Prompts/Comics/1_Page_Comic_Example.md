Learning Experience Request (LER)
1. Learning Goal

Learn what an If-Else Statement is.

2. Target Audience

School Student (Beginner)

3. Prior Knowledge

Knows how to make simple everyday decisions.

4. Learning Objective

Understand how a computer chooses between two different actions based on a condition.

5. Preferred Representation

Comic

6. Preferred Learning Style

Story-based + Visual

7. Scenario / Environment Preference

Fantasy Kingdom

8. Constraints
8–10 minutes
Beginner friendly
No programming syntax until the end
Colorful characters
Fun dialogue
9. Output Requirements
Comic panels
Character dialogues
Visual expressions
Small recap
One practice activity
One misconception section
10. Additional Notes

The comic should feel like reading an adventure where the reader discovers the idea naturally before seeing any programming example.
