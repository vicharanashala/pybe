# CKLIS Architecture Evolution Proposal & Reference Manual

**Document ID:** CKLIS-AEP-001 & Reference Manual v1.0.0
**Project:** Code Katha Learning Intelligence System (CKLIS)

## Architecture Overview
CKLIS is structured across 4 primary layers:
1. FOUNDATION: Project Charter, Constitution, Learning Science
2. EDUCATIONAL REASONING LAYER: Misconception, Mental Model, Scenario Intelligence, Pattern Mapping, Episode Generation Engines
3. OPERATIONS & GOVERNANCE: Production Engine, Quality Engine, Evolution Engine, CKMS
4. SUPPORTING ASSETS & REGISTRIES: Representation Registry, Scenario Domain Registry, Character Registry, Production Profile Registry

## Key Invariants
- Educational Reasoning remains representation-independent.
- Scenarios and characters are procedurally generated or managed assets.
- Quality Engine holds independent review authority.
- The 7-step execution pipeline is immutable.
