# 13 – Learning Experience Specification (LES)

**Document ID:** CKLIS-LES-001
**Version:** 1.0.0 / 2.0.0

## 1. Purpose
Standardized request model defining learner intent independently of educational execution.

## 2. Request Contract
- Educational Intent / Topic (Required)
- Desired Output / Deliverable Format (Required)
- Target Audience (Optional, Default: General Learner)
- Educational Representation (Optional, Default: Story/Lesson)
- Programming Language (Optional, Default: Python)
- Teaching Style (Optional, Default: Concept-first)
- Experience Hints / Procedural Environment (Optional)
- Experience Constraints (Optional)
