# 02 – Learning Science

## 1. Purpose
Defines the scientific and educational foundations upon which CKLIS is built. Unlike the Constitution (which defines mandatory laws), this specification explains WHY those laws improve learning and how they should influence every educational episode.

## 2. Educational Philosophy
Learning occurs when learners construct accurate mental models through guided experiences, not when they memorize isolated facts or syntax. Programming is treated as understanding systems, not remembering language features.

Learner transformation: Observer → Pattern Recognizer → Concept Builder → Programmer → Problem Solver

## 3. Canonical Learning Pathway
Experience → Observation → Pattern Recognition → Mental Model Construction → Programming Concept → Implementation → Application → Reflection

Each stage prepares the learner for the next. Skipping stages increases the likelihood of fragile understanding and rote memorization. This operationalizes CL-02, CL-03, CL-04, CL-07, CL-18.

## 4. Learning Principles

**LP-01 — Knowledge Is Constructed**: Learners actively build understanding by connecting new information to existing knowledge. Knowledge cannot simply be transferred. CKLIS Implication: Activate existing learner experiences before introducing unfamiliar concepts. (Supports CL-02, CL-03, CL-07)

**LP-02 — Misconceptions Compete With Correct Models**: Learners already possess beliefs about how systems work — some correct, some incomplete, some incorrect. Effective education replaces inaccurate mental models. CKLIS Implication: Identify probable misconceptions before selecting explanations. (Supports CL-06, CL-07)

**LP-03 — Mental Models Drive Expertise**: Experts solve problems efficiently because they possess well-organized mental models, not larger collections of memorized facts. CKLIS Implication: Every lesson SHOULD strengthen one dominant mental model. The strongest reinforcement usually comes from revisiting the same scenario. (Supports CL-07, CL-22)

**LP-04 — Context Improves Understanding**: Learners understand abstract ideas more easily when introduced through meaningful contexts. Scenarios reduce abstraction by providing observable situations. CKLIS Implication: Scenario selection should maximize conceptual clarity, not entertainment value. (Supports CL-03, CL-08, CL-13)

**LP-05 — Pattern Recognition Precedes Abstraction**: Humans naturally recognize repeated structures before forming abstract rules. CKLIS Implication: Encourage learners to observe recurring behavior before introducing terminology. (Supports CL-08, CL-16)

**LP-06 — Cognitive Load Must Be Managed**: Working memory has limited capacity. Learning deteriorates when explanations introduce unnecessary complexity. CKLIS Implication: Introduce only the information necessary for the current learning objective. (Supports CL-21, CL-14)

**LP-07 — Active Thinking Produces Stronger Learning**: Learners remember concepts more effectively when they actively predict, compare, explain, or solve problems. CKLIS Implication: Include opportunities for learners to think before receiving the explanation. (Supports CL-17, CL-25)

**LP-08 — Retrieval Strengthens Memory**: Learning is strengthened when learners actively recall information rather than re-read or re-watch it. CKLIS Implication: Include opportunities for learners to predict outcomes, answer questions, or mentally reconstruct concepts. (Supports CL-18, CL-25)

**LP-09 — Knowledge Transfers Through Abstraction**: True understanding is demonstrated when learners apply a concept in a new context. CKLIS Implication: Conclude by connecting the current concept to at least one new scenario or problem domain. Teach the transferable pattern, not the specific example. (Supports CL-08, CL-19)

**LP-10 — Feedback Refines Mental Models**: Learners improve when they compare their predictions with actual outcomes. CKLIS Implication: Expose common mistakes, explain why they occur, and demonstrate the correct reasoning process. (Supports CL-06, CL-18, CL-20)

## 6. Design Implications for All Engines
1. Educational decisions are driven by learning science before content production.
2. Mental model construction is the primary indicator of learning success.
3. Scenarios exist to reveal patterns, not to entertain in isolation.
4. Misconception analysis is a required design activity, not optional.
5. Pattern recognition bridges concrete experience and abstract programming concepts.
6. Practice and reflection complete the learning cycle.
7. Quality evaluation should assess conceptual understanding in addition to technical accuracy.
