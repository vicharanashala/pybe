Master Pedagogical, Theoretical & Technical Architecture Matrix

The complete 8-layer CKLIS architectural breakdown mapping every layer to its core question, educational theory & author, brief theoretical concept, pedagogical alignment rationale, and exact technical engine mechanics.

Layer # & Name Core Question Answered Theory & Author(s) Brief Theory Concept How Layer Follows Theory How Layer Works Technically
Pre-Step
Objective Engine		 What exact mechanism must the student master? Taxonomy of Educational Objectives
(Benjamin Bloom)		 Educational goals must be classified into cognitive depth levels, prioritizing mechanical comprehension over syntax recall. Formulates a single measurable goal targeting underlying system execution, preventing surface-level memorization before lesson generation. Executes PRE-STEP prompt with topic & audience; generates a 1-sentence Bloom's taxonomy objective that anchors downstream steps.
Layer 1
Misconception Engine (MIS-01)		 What false assumptions will confuse the student? Conceptual Change Theory
(David Ausubel & Posner et al.)		 Learners hold prior beliefs. If false priors are not confronted, learners distort new info to fit bad mental models. Identifies and dismantles misconception traps before presenting code (CL-06, LP-02), creating necessary cognitive conflict. Calls LLM prompt MIS-01 to output JSON misconceptions[] array with probability, severity, and correctionStrategy.
Layer 2
Mental Model Engine (MM-01)		 What physical analogy re-wires their intuition? Mental Model Theory
(Donald Norman, Kenneth Craik, P. Johnson-Laird)		 Experts reason by running internal mental simulations of cause-and-effect systems rather than recalling text syntax rules. Constructs a dominant physical model & visual strategy to transform false assumptions into strong intuition (CL-07, LP-03). Calls MM-01 prompt using Layer 1 output; returns JSON with modelName, description, coreAnalogy, and visualizationStrategy.
Layer 3
Scenario Intelligence Engine (SCN-01)		 What authentic real-world story naturally models this? Situated Cognition & Constructivism
(Jean Piaget, Lev Vygotsky, John Bransford)		 Knowledge is rooted in authentic physical contexts. Abstract rules cannot be assimilated without prior physical observation. Grounds CS concepts in real historical/natural stories with 100% physical fidelity before any code is introduced (CL-03, CL-13, LP-04). Mode 1 discovers real domain stories; Mode 2 locks user observation anchor (0% fake mechanics); outputs character & env seeds.
Layer 4
Pattern Mapping Engine (PAT-01)		 How does physical story behavior map to code rules? Inductive Reasoning & Transfer of Learning
(John Bransford & Piaget Schema Abstraction)		 Far transfer occurs when learners extract schema invariants across multiple representations (concrete instance → abstract rule). Bridges story events directly to programming invariants using story-evoking pattern names to enable transfer (CL-08, LP-05, LP-09). Executes PAT-01 prompt taking story context; extracts 3 tiers: Observable Event → Abstract Invariant → Code Syntax.
Layer 5
Cognitive Load Manager		 How do we keep working memory from overflowing? Cognitive Load Theory & Multimedia Learning
(John Sweller & Richard Mayer)		 Working memory capacity is strictly limited (~4 elements). Extraneous info degrades learning, while germane processing builds schemas. Caps lesson to 1 core learning objective and strips non-essential content to prevent cognitive overload (CL-05, CL-14, LP-06). Intercepts intermediate representations; filters extraneous domain clutter and enforces single objective brief before episode generation.
Layer 6
Episode Generation Engine (EPI-01)		 What sequence of story chapters creates the 'aha!' moment? Gagné's 9 Events of Instruction & Deliberate Practice
(Robert Gagné, Richard Mayer, Anders Ericsson)		 Effective instruction follows an ordered sequence (Gain Attention → Present Stimulus → Guide Learning → Elicit Performance). Sequences 4 canonical chapters (Observation Hook → Pattern Discovery → Code Bridge → Transfer Reflection) (CL-04). Runs 2-Pass pipeline: Pass 1 generates Production Blueprint (Character/Env Bibles); Pass 2 outputs scenes + 200+ word AI image prompts.
Layer 7
Active Retrieval & Reflection Engine		 How do we solidify long-term memory retention? Retrieval Practice & Desirable Difficulties
(Robert Bjork & Anders Ericsson)		 Memory is consolidated not by passive re-reading, but by forced active recall and self-explanation (The Testing Effect). Embeds interactive prediction checkpoints and reflection questions post-generation (CL-17, CL-18, LP-07, LP-08). Post-processes generated episodes to insert prediction gates (predict before reveal), comprehension checkpoints, and transfer prompts.
Layer 8
Quality Governance Engine (QUA-01)		 Does this strictly follow all educational laws without shortcuts? Cybernetic Systems & Formative Evaluation
(Michael Scriven)		 Quality assurance requires an independent audit feedback loop separated from the production system to eliminate confirmation bias. Audits completed output against Constitutional Directives (CL-01 to CL-16) to guarantee 0% fake analogies (QP-01). Runs QUA-01 prompt evaluating 9 quality dimensions QD-01 to QD-09. If score <85, identifies failing engine & triggers up to 3 retries.

Theoretical Foundation — Why This Many Layers?

PyBe does not follow one single educational theory. It synthesises six complementary scientific theories into a unified pedagogical pipeline — each layer exists because one theory demands it.

PyBe follows Six Integrated Theories,
not one — by constitutional design.

"PyBe does not require adherence to any single educational theory. Instead, it integrates complementary ideas where they align with the project's educational objectives."

Each of the 8 engines maps to at least one distinct scientific theory. Collapsing to fewer theories would eliminate at least one engine, breaking the constitutional guarantee of pedagogical fidelity.

Why 8 Engines — Not 7, Not 9?
Each layer is necessary because the theory it operationalises cannot be merged with an adjacent stage without violating constitutional law. Removing any engine collapses at least one of the six scientific guarantees.
01
Misconception Engine
Must precede mental model construction — Conceptual Change Theory (Ausubel) proves that incorrect priors block assimilation of new knowledge if not addressed first (CL-06).
Critical
02
Mental Model Engine
Must precede scenario selection — Norman proved that learners need an internal causal simulation before a concrete example will anchor meaningfully (CL-07).
Critical
03
Scenario Intelligence Engine
Must precede pattern mapping — Piaget's concrete-operational stage proves learners cannot induce abstract rules without first observing them in familiar physical contexts (CL-03).
Critical
04
Pattern Mapping Engine
Cannot be merged with Scenario Engine — Bransford's Transfer of Learning research proves the bridging step (Observable to Abstract to Programming) is a cognitively distinct operation (CL-08, LP-09).
Critical

Cognitive Load Manager
Must be a gate between pattern extraction and episode generation — Sweller proved working memory collapse degrades retention if extraneous material is allowed into the final episode (LP-06, CL-05).
Essential
06
Episode Generation Engine
Enforces Gagne's immutable 9-event sequence — collapsing this into any other stage breaks the constitutional guarantee that mechanism always precedes implementation (CL-04).
Critical

Bjork's Desirable Difficulties research proves retrieval must be a post-generation pass — embedding prediction prompts during generation would violate the sequencing required by CL-17 and CL-18.

6 Theories — With Proof of Integration

Each theory is mapped to its exact PyBe constitutional law, learning principle, and operational mechanism.

1
Constructivist Learning Theory
Jean Piaget · Lev Vygotsky
Learners actively construct understanding by connecting new information to existing knowledge structures, progressing from concrete experience to abstract rules.
PyBe Proof of Integration
LP-01 "Knowledge Is Constructed" · CL-16 "Progressive Abstraction" · The canonical 9-stage pathway (Experience to Observation to Pattern to Mental Model to Concept to Code to Practice to Reflection) operationalises Piaget's concrete-to-formal progression in every lesson.
2
Conceptual Change Theory
David Ausubel · Posner et al.
True learning requires creating cognitive conflict to replace incorrect mental models. Learners do not begin with empty minds — bad priors must be disrupted before new schemas can form.
PyBe Proof of Integration
CL-06 mandates misconception resolution before code · LP-02 "Misconceptions Compete With Correct Models" · MC-01 to MC-05 classify exact misconception types · IS-01 to IS-07 prescribe corrective interventions (prediction, counterexample, reflection).
3
Mental Model Theory
Donald Norman · Kenneth Craik · Philip Johnson-Laird
Experts reason about systems by running internal conceptual simulations — mental models — of cause-and-effect, not by recalling memorized syntax.
PyBe Proof of Integration
CL-07 "Mental Models Are Mandatory — Code Alone Is Never Sufficient" · LP-03 "Mental Models Drive Expertise" · MT-01 to MT-05 type taxonomy (State, Flow, Relationship, Transformation, System) · MM-01 to MM-05 structural specification.
4
Cognitive Load Theory & Multimedia Learning
John Sweller · Richard Mayer
Human working memory has strict limits. Instructional efficiency degrades rapidly when lessons introduce unnecessary complexity or extraneous distractions beyond ~4 novel elements.
PyBe Proof of Integration (Very High Confidence)
LP-06 "Working Memory Has Limited Capacity" · CL-05 "One Core Learning Objective Per Lesson" · CL-14 "Simplicity Over Cleverness" · CL-21 "Clarity Over Complexity" · QD-06 Educational Clarity audit before every publication. Rated Very High confidence — the only theory with that rating.
5
Transfer of Learning & Inductive Pattern Recognition
John Bransford · Jean Piaget Schema Abstraction
Far transfer occurs when a learner extracts an abstract rule from a specific instance and maps it to a new domain. Humans recognise patterns before forming abstract generalisations.
PyBe Proof of Integration
CL-08 "Scenarios Are Not the Destination — Scenario to Observation to Pattern to Concept" · LP-05 "Pattern Recognition Precedes Abstraction" · LP-09 "Abstraction Enables Transfer" · Three explicit tiers: PM-01 Observable to PM-02 Abstract to PM-03 Programming Pattern.
6
Active Learning & Retrieval Practice
Robert Bjork · Anders Ericsson
Passive consumption produces weak retention. Long-term memory is consolidated when learners actively predict, recall, self-explain, and reflect — the Testing Effect.
PyBe Proof of Integration
LP-07 "Active Thinking Produces Stronger Learning" · LP-08 "Retrieval Strengthens Memory" · CL-17 "Active Curiosity — Predict Before Reveal" · CL-18 "Reflection Completes Learning" · CL-25 "Practice Reinforces Understanding" · Stage 7 is a dedicated retrieval pass post-generation.
