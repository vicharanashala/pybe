# PyBe — Product Vision & CKLIS Framework

## 1. Product Vision & Educational Thesis

Traditional computer science education often suffers from two major pitfalls:
1. **Abstract Syntax Overload**: Students are overwhelmed by language syntax before understanding the underlying physical mechanism.
2. **Artificial & Forced Analogies**: Generic analogies (*e.g., comparing variables to post-office boxes or traffic lights*) fail because they lack real-world physical invariants and cultural resonance.

**PyBe** addresses this problem by introducing the **Concept-Knowledge Learning Intelligence System (CKLIS)**. PyBe grounds programming concepts directly in **authentic real-world physical observations, historical anecdotes, and cultural fables** (*e.g., The Thirsty Crow, Vikram and Betaal, Akbar and Birbal, Vijaya Stambha*).

Instead of inventing synthetic stories, PyBe maps real-world state changes line-by-line to executable code invariants (*e.g., `water_level += 0.2` or `while betaal_captured: if silence_broken: betaal.fly_back()`*).

## 3. The 5 PyBe Studio Deliverable Modes

PyBe transforms the 7-step CKLIS analysis into 5 distinct presentation formats:

### 1. 🎨 Short Comic (1-Page)
- **Format**: 4 to 5 panels total on a single page.
- **Content**: Story Hook → Physical Observation → Pattern Discovery → Code Bridge.
- **Visual Staging**: 60–80 word self-contained AI image prompts with copy-paste prompt buttons.
- **Code Staging**: Final panel contains executable Python code directly mapping physical state updates.

### 2. 📚 Long Comic (Multi-Page)
- **Format**: 2-pass generation (CP1 Blueprint → CP2 Panel Scripts).
- **Content**: 6 to 8 panels across multiple pages with Character Bible, Environment Bible, and panel composition rules.

### 3. 🎬 Concept Explainer Video Script
- **Format**: 2-pass generation (VP1 Production Blueprint → VP2 Scene Breakdown).
- **Content**: 6 to 10 second scenes with 15 sub-fields per scene, including SnapGenAI 3D motion prompts, camera direction, narration, and audio cues.

### 4. 📖 Split-Screen Storybook
- **Format**: Interactive Storybook.
- **Content**: Left side features image prompt + embedded dialogue balloon; right side features story prose, code concept bridge, and executable Python code snippet.

### 5. 🎙️ Audio Podcast
- **Format**: Scripted Dual-Host Dialogue.
- **Content**: Conversational script between Educational Host (*Alex*) and Inquisitive Co-Host (*Dr. Sam*), complete with sound effects and code discussion.
