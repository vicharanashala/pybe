# Case studies — folk tales mapped to Python concepts

Each file below takes one folk tale the reader is likely to already know, retells it, and then shows the single point where the story's logic and a Python construct turn out to be the same shape. A table lines the story's parts up against the code, the same rule appears as a runnable snippet, and a closing note says where the analogy breaks — because a mapping that is never qualified quietly becomes a misconception.

Three questions end every case study: locate the construct inside the story, read it in Python, then apply it to a situation the story never mentioned. That third one is what separates learning the concept from learning the tale. Answer keys are folded at the bottom of each file, so the questions can be attempted first.

**19 concepts across 25 tellings.** 6 concepts carry a second, independent tale for the same construct, so a reader who does not know the first one still has a way in. Those rows are marked **2 tellings**.
