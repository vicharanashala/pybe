# Garbage Collector Stories

Build the attached PyBay “Garbage Collection: The One Library Book” specification as a polished interactive visual storytelling web experience using HTML, CSS, and JavaScript. Follow the document’s learning flow and make the concepts visual, illustrated, and interactive rather than a conventional article layout.
