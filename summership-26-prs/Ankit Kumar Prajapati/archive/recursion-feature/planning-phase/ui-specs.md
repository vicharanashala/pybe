# UI Specs

## 1. `<announcement> </announcement>`

- Display the content inside a highlighted rectangular container.
- Use a subtle background that is visually different from the normal story text.
- Add a thin accent-colored border on the left side.
- Use rounded corners.
- Add sufficient horizontal and vertical padding.
- The announcement text should be slightly emphasized compared to normal story text.
- Use italic text for the announcement content.
- The announcement container should occupy the natural width of the content area.
- Add appropriate vertical spacing before and after the announcement.
- Do not use icons or additional decorative elements.
- When the announcement is revealed, use a short fade-in animation.
