## The Idea: Interactive Iteration Learning Module
This project is a scenario-driven learning module designed to teach Python loop constructs (`for` and `while` loops). 

The module uses a relatable real-world analogy—finding a seat in a dark movie theater—to contrast condition-dependent repetition (a person searching for an unknown row) with fixed-repetition (a theater usher distributing water to a known number of rows). It utilizes a custom-built, split-screen React application to deliver 18 interactive story beats, including multiple-choice knowledge checks and incremental code building.
