# 🐍 Python Keyword Explorer + Quiz

## Overview

Python Keyword Explorer + Quiz is an interactive learning tool for beginners who want to understand Python keywords and test their knowledge.

The feature combines a searchable keyword reference with an interactive multiple-choice quiz.

## Features

### 📚 Keyword Explorer

- Search Python keywords
- Filter keywords by category
- View keyword descriptions
- View syntax
- View examples
- View expected output

### 🧠 Interactive Quiz

- Randomly selects 5 questions
- Multiple-choice questions
- Randomized answer options
- Instant feedback
- Correct answer highlighting
- Score tracking
- Progress bar
- Final result
- Restart quiz
