# 🐍 The Lost Library of Python

Interactive story-driven web app that teaches all **37 Python keywords** through a magical library adventure and drag-and-drop puzzles.

---

## 🎯 Overview

This project introduces an interactive learning experience where users explore Python keywords inside a story-based library world and solve execution path puzzles.

---

## ✨ Highlights

- Story-driven Python keyword learning
- 37 keywords with explanations and code examples
- Category-based filtering
- Drag-and-drop puzzle chamber
- 5 random puzzles generated on every visit
- XP and scoring system
- Final result badge
- Fully responsive design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG

---

## 🚀 Quick Start

1. Clone the repository
2. Open `index.html` in your browser

No installation or build step required.
