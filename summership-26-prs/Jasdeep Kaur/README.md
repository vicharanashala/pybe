## 🎯 PR Overview (Jasdeep Kaur's Contribution)

### Added Topic: 🐼 Poko's Story-Driven Variables Learning
This submission provides a complete story-based learning experience where learners discover Python concepts through Poko the Panda's adventures:

1. **Story Intro**: Meet Poko preparing Honey Cave for winter.
2. **Observation**: Observe food supplies, water, coins, and health status.
3. **Interactive Questions**: Answer guided story-based questions.
4. **Pattern Discovery**: Discover how variables organize information.
5. **Concept Reveal**: Learn Python variable syntax (`int`, `str`, `float`, `bool`).
6. **Guided Practice**: Complete interactive coding activities.
7. **Python Syntax**: Practice Python naming conventions and assignment operators.
8. **Coding Challenge**: Solve independent variable tasks.
9. **Case Study**: Apply variable logic to real-world scenario challenges.
10. **Grand Challenge**: Complete the final evaluation.
11. **Rewards & Leaderboard**: Track XP, badges, and progress.

## 🛠️ Tech Stack & Architecture

- **Frontend**: React + Vite + Framer Motion + GSAP
- **Backend**: Express.js + Node.js (Port `5000`)
- **Styling**: Storybook & Nature-inspired Vanilla CSS
- **Interpreting**: In-browser Python interpreter engine

## 🚀 Quick Start

### 1. Install Dependencies

```bash
npm run installAll
```

### 2. Run Development Server

```bash
npm run dev
```

- **Frontend App**: [http://localhost:5173](http://localhost:5173)
- **Backend API**: [http://localhost:5000/api](http://localhost:5000/api)
