# PyBe MERN App Wiki — Jasdeep Kaur Submission

## What is PyBe MERN App?
PyBe is a prototype learning application for Python that uses scenario-driven sessions and interactive concepts to help learners practice reasoning, abstraction, and Python construct generation. It is built as a local MERN-style application with JSON-backed APIs.

## Key Purpose
The project is designed to demonstrate a proof-of-concept for a Python learning experience that:
- Presents curated story scenarios featuring Poko the Panda
- Guides learners through reasoning and abstraction mapping
- Generates Python constructs from user interactions
- Tracks progress and session insights
- Provides a roadmap of learning goals

## Main Features
- Story-driven learning browser with interactive stages
- Reasoning support, abstraction mapping, and score tracking
- Visual memory cards for Python variables (`str`, `int`, `float`, `bool`)
- In-browser sandboxed Python execution
- Gamified metrics (XP, Badges, Leaderboards)

## Technology Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- UI: Plain CSS (Storybook Nature Theme)

## Getting Started
### Install Dependencies
```bash
npm run installAll
```

### Run the App
```bash
npm run dev
```

Visit:
- Frontend: http://localhost:5173
- API: http://localhost:5000/api
