CHAPTER 01

The Problem of Endless Work

Captain Zephyr

Every day I fly to the floating islands to collect Wind Crystals.

But writing the same flying instructions again and again is exhausting and error-prone.

There has to be a smarter way… a way to tell the computer:

“Do this action multiple times for me.”

That smarter way is called a Loop.

💡
Key Insight

Loops exist so humans don’t have to repeat themselves. The computer does the repetition.

CHAPTER 02

Your Loop Toolkit

Five essential tools every Python explorer needs.

🌀

for

Known count

Repeat a fixed number of times.

for i in range(5):
    collect()
♾️

while

Condition based

Repeat while a condition stays true.

while energy > 0:
    fly()
🔢

range()

Number maker

Creates sequences for for-loops.

range(5) → 0 1 2 3 4
⏭️

continue

Skip once

Skip the rest of this turn only.

if storm:
    continue
🛑

break

Stop completely

Exit the loop immediately.

if danger:
    break
