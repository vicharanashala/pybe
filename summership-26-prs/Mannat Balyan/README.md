# The Wind Crystal Chase

An interactive way to learn Python loops (`for`, `while`, `range()`, `break`, `continue`).

Help Captain Zephyr collect wind crystals across floating islands.

## What you will learn

- `for` loops and `range()`
- `while` loops
- `continue` (skip something)
- `break` (stop the loop)

## How to run

Just open the `index.html` file in your browser.  
No installation needed.

## Files

- `index.html` – the main page
- `style.css` – design and animations
- `script.js` – all the interactive parts
- `assets/` – pictures (SVG)

## Features

- Fun story with Captain Zephyr
- Puzzles
- XP and badges
- Responsive design
