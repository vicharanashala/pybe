# Tiffin Trail

## Run locally

1. Open this folder in VS Code.
2. Open a terminal (Terminal → New Terminal) and run:

   ```bash
   npm install
   npm run dev
   ```

3. Open the URL shown in the terminal (usually http://localhost:5173).

## Notes
- Requires Node.js 18+ installed on your machine.
- Built with Vite + React + Tailwind CSS + lucide-react icons.
- Main component: `src/TiffinTrail.jsx`
