The app will automatically pick them up (and quietly falls back to the
illustrated version if a file is missing).

## Where to get free images
- unsplash.com  (free to use, no attribution required)
- pexels.com    (free to use, no attribution required)
- pixabay.com   (free to use, no attribution required)

Download at ~1200x700 or larger, rename to match the table above,
and place directly in this folder (public/images/).

Recommended size: under 300KB each (compress with squoosh.app if needed).
