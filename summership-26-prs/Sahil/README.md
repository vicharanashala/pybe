# 🛸 PyBe: Translators, Compilers & Interpreters

> **Learn how computers understand code through a fun Human & Alien story.** 🌍👽

PyBe is an interactive educational case study that introduces beginners to the basic concepts of **translators, compilers, and interpreters** through a simple story-driven experience.

Instead of starting with complex compiler theory, PyBe uses a Human & Alien scenario to make the concepts easier to understand and remember.

---

## 🌟 What You'll Learn

Through the interactive experience, you'll explore:

* 🌍 Why translation is needed
* 🔄 What a translator does
* 💻 How programming languages are translated
* ⚙️ What a compiler is
* ▶️ What an interpreter is
* 🧩 The difference between compilation and interpretation
* 🧠 How translated code eventually gets executed

> **Learning goal:** Build an intuitive understanding of how programming languages are processed without diving into complicated compiler-design theory.

---

## 📖 Learning Through Story

PyBe uses a **Human & Alien** story to introduce programming concepts in a way that feels natural rather than purely theoretical.

The learner follows the characters through different situations and gradually discovers the purpose of translation in programming.

The story is supported by interactive content and quizzes to reinforce each concept.

## 🧠 Learning Flow

The case study follows a gradual learning path:

```text
Human & Alien Story
        │
        ▼
Why Translation is Needed
        │
        ▼
What Translation Means
        │
        ▼
How Programming Code is Translated
        │
        ├───────────────┐
        ▼               ▼
    Compiler       Interpreter
        │               │
        └───────┬───────┘
                ▼
          Code Execution
```

Each part focuses on one clear learning objective so that learners can understand the concept before moving forward.
