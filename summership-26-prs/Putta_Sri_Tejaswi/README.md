# PyBe -- Story-Driven Python Learning Platform

> *"Hear the story. Think about it. Discover the idea. Use it in Python."*

PyBe teaches Python through ancient Indian storytelling traditions. Every topic begins with a complete story from Panchatantra, Jataka Tales, Akbar-Birbal, or other Indian narrative traditions. The learner reads the story, discovers the computational thinking naturally, and then learns Python -- following the ancient pedagogy of **Shravana, Manana, Nididhyasana, and Prayoga**.

---

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:5173` to start learning.

---

## Key Features

### 1. Story-Driven Python Learning

Every topic begins with a complete story set in ancient Indian traditions -- Panchatantra, Jataka Tales, Akbar-Birbal, Vikram-Betal, and more. Stories never mention Python until the concept is discovered naturally.

### 2. Concept-Before-Code Pedagogy

Learners understand the idea first through narrative, then discover Python implementation. Each step maps to one of 9 Sanskrit learning stages: Shravana (listen) -> Manana (contemplate) -> Nididhyasana (discover) -> Prayoga (apply).

### 3. Interactive 14-Step Learning Journey

Every topic follows a complete pipeline:

```
Story Introduction -> Problem Scenes -> Solution Scenes -> Activity
-> Concept Guide -> Bridge -> Lesson -> Playground -> Challenge
-> Reflection -> AI Mentor -> Completion -> Dashboard
```

### 4. AI-Assisted Learning Experience

- **AI Mentor** guides reflection and concept understanding
- **AI-Generated Character Portraits** via Pollinations.ai (no API key needed)
- **Reflection Evaluation** scoring across 6 dimensions: communication, reasoning, reflection, critical thinking, creativity, prompt quality

### 5. Gamified Progress System

- **5 Learning Levels** with progressive unlock thresholds
- **63 Collectible Character Cards** (3 per topic, 3 rarity tiers)
- **9 Tradition Artifacts** + **21 Topic Gadgets**
- **Full Dashboard** with learning journey visualization

### 6. Interactive Coding Practice

- **Lightweight Python Playground** with variable simulation
- **6 Activity Types**: drag-labels, click-order, gate-check, arrange-order, repeat-click, match-pairs
- **Code Block Challenges** with immediate feedback

### 7. Personalized Topic-Based Learning

21 Python topics, each with its own story world, characters, visual theme, and interactive activities. Topics range from Variables and Arithmetic to Dictionaries, Sorting, and Modules.

## Tech Stack

| Technology | Purpose |
|---|---|
| React 19 | UI framework |
| TypeScript 6 | Type safety |
| Vite 8 | Build tool |
| Tailwind CSS | Styling |
| Pollinations.ai | Free AI image generation |
| Web Speech API | Voice narration |

**No backend, no API keys, no external services** -- entirely client-side.
