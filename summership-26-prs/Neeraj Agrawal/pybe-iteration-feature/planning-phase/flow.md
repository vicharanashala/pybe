# Flow

This document describes the sequence and flow of the learning module for teaching Iteration.

## 1. Interactive Case Study
- Present the case study as an immersive, full-screen narrative with visually rich context (e.g., Cricket Stadium for loops, Bank Note Counter for control statements).
- Encourage the learner to visualize the physical process before diving into syntax.
- The objective of this stage is to help the learner understand the underlying problem-solving approach (e.g., counting a known number of items vs. waiting for a condition).

---

## 2. Reveal the Concept
- Explain how Python handles the repetitive actions described in the case study.
- Introduce the following concepts mapping directly to the story:
  - `for` loop (The Bowler's exact 6 deliveries)
  - `while` loop (The Batsmen chasing a target)
  - `continue` (Skipping the Torn Note)
  - `break` (Halting completely for a Fake Note)
- Reinforce the concepts through multiple-choice pop-up quizzes (Concept Checks).
- The learner must answer correctly to unlock the next progression step.

---

## 3. Code Challenge (Application)
- Show how the same idea can be implemented in actual Python code.
- Provide a hands-on code-completion exercise where learners type in the missing loop keywords (`for`, `while`, `continue`, `break`).
- Verify the code instantly and provide visual feedback.
- Upon successful completion, the next case study is unlocked.
