# The Messy Attendance List — a string manipulation case study

## What's here

- **`case-study.md`** — the case study itself: a real-world scenario
  about cleaning up a messy, duplicate-riddled attendance list,
  walked through step by step, ending in the Python solution.
- **`attendance_cleaner.py`** — the working code from the case study,
  as a standalone, runnable script.
- **`test_attendance_cleaner.py`** — 7 tests covering the main example
  plus edge cases (duplicates with mixed casing, trailing commas, a
  single name, an empty string, and a documented scope boundary around
  internal double spaces).

## How to run it

No dependencies needed — just plain Python 3.

```bash
python3 attendance_cleaner.py          # runs the case study's example
python3 test_attendance_cleaner.py     # runs the test suite (7/7 passing)
```
