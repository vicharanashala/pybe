# Changes

## Added

### Interactive Class Concept Case Study

Added a dedicated interactive learning experience for the Python **Classes** concept.

The contribution adds a continuous case-study flow covering:

- generic Flower representation
- generic Car representation
- generic Human representation
- comparison of the three representations
- identification of the common structural pattern
- generic Student card
- Student-card identification interaction
- large-scale student scenario
- repetition/pain experience
- reusable-design interaction
- multiple student details using the same structure
- structure-to-specific-example matching
- transition from real-world representation to Python
- interactive construction of `class Student`
- transition toward the next concept

## Learning Flow Changes

The contribution introduces a progressive teaching flow:

**Concept Discovery**
→ **Need for the Concept**
→ **Programming Representation**
→ **Question for the Next Concept**

### Concept Discovery

The learner first encounters multiple real-world representations and identifies the common pattern between them.

The learner then transfers the pattern to the Student card.

### Need for the Concept

The learner is presented with a large number of students and experiences the problem of repeatedly creating the same structure.

The learner discovers that one design can be reused with different details.

The reusable structure is then mapped to Python through:
