# Context

## Relationship to PyBe V0

PyBe V0 provides the basic foundation for delivering Python learning content.

This contribution extends that foundation with a deeper case-study-driven learning experience for the concept of Classes.

The objective is not simply to add more content about Classes, but to introduce a different way of taking the learner through a programming concept.

## Problem

When a programming concept is introduced directly through its definition or syntax, the learner can understand what to write without necessarily understanding why the concept exists.
